# Landing Page

## Structure du projet

```
project/
├── existing-store/                  # Boutique actuelle (état de référence)
└── experiments/
    └── bubble-mousse-premium/
        ├── docs/                    # Brief, specs, notes de décision
        ├── references/              # Inspirations, benchmarks, captures
        ├── prototype/               # Maquettes et versions jetables
        ├── assets/                  # Images, vidéos, polices, icônes
        └── implementation/          # Code final destiné à la production
```

Les dossiers vides sont conservés via des fichiers `.gitkeep`, à supprimer dès
qu'un vrai fichier est ajouté.
