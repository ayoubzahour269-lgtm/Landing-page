# Invocation Examples

## Direct invocation

```text
/premium-landing-page-designer Create a premium animated landing page for a cosmetic serum from the product images in this repository. Mobile traffic is the priority. Discuss two visual directions first, then implement the strongest one.
```

```text
/premium-landing-page-designer Audit the current homepage. Keep the existing Next.js stack, improve the luxury art direction, simplify the motion system, and fix mobile conversion problems.
```

```text
/premium-landing-page-designer Build a single-product landing page with a cinematic hero and one lightweight 3D interaction. Use the existing brand colors and checkout flow. Do not invent copy or reviews.
```

## Natural-language triggering

```text
Design and implement a premium ecommerce landing page for this product. I want fluid motion, a strong editorial look, and a 3D product moment without making the site slow.
```

```text
Turn the current product page into a high-converting animated landing page for paid social traffic. Preserve the existing cart integration.
```
